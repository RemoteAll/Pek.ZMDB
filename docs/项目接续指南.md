## 1. 项目是什么

C# `Pek.MDB` / Rust `Pek.RMDB` 的 **Zig 0.17.1** 实现：面向「读多写少、内存为主、JSON 异步持久化」的内存数据库。

| 模块 | 内容 |
|---|---|
| `src/value.zig` | `zzig.db.Value` → 类型感知索引键 `Key`（文本/整数/浮点/布尔/Unix 秒）；`yyyy-MM-dd HH:mm:ss` 与年/月/日区间 |
| `src/model.zig` | `Field`（构造器链）、单/复合唯一规则、统计结构、`Violation` 冲突出参、`Condition` |
| `src/entity.zig` | 实体 comptime 契约 + `Ref(T)`（原子引用计数）+ `List`/`Page` |
| `src/ordered.zig` | 随机化 Treap 有序映射 + 升序 `IdSet`（Zig std 无 `BTreeMap`） |
| `src/index.zig` | 文本（精确 / 大小写不敏感 / 前缀 / 包含 / `*`·`?`）、数值·时间有序、布尔双桶、JSON 文本 |
| `src/unique.zig` | 单字段与复合唯一约束（两阶段写入、更新 diff、空值语义） |
| `src/json.zig` | C# `SimpleJsonString` 宽容词法（裸键/注释/尾逗号）+ C# 口径序列化；值树复用 `zzig.web.Value` |
| `src/table.zig` | 单表 `std.Io.RwLock` 状态机、CRUD、索引 diff、分页、快照、原子落盘、`AnyTable` vtable |
| `src/db.zig` | `MemoryDb` 多实例 + 后台写合并线程 + 全局 `cdb` 风格入口 |
| `src/persist.zig` | 写合并 `Hub`（Mutex+Condition+最小间隔）、路径清洗、`fsio` 封装 |
| `src/fixtures.zig` / `src/tests.zig` | 测试实体与 60 个集成测试 |
| `examples/basic.zig` | 端到端示例（可重复运行） |
| `tools/regression.ps1` | 一键回归（fmt → Debug → ReleaseFast → 示例） |
| `tools/continuity/` | 自检安装 + 记忆同步 + 用户级指令模板 |
| `docs/与C#对照.md` | API/语义映射、有意差异、**zzig 复用检索证据** |

## 3. 关键设计（改动前必读）

1. **实体契约**（`src/entity.zig` 顶部）：`type_name` / `fields` / `initEmpty` / `deinit` / `getId` / `setId` /
   `getField` / `setField`；`getName`/`setName`、`composite_uniques`、`not_save` 可选。`getField` 返回**借用**值。
2. **所有权**：写操作失败由库 `deinit`；成功归库；查询结果调用方释放。`insertBatch` 冲突时已插入行保留。
3. **索引**：`Id`/`Name` 自动建索引；`notIndexed` 字段无槽位，查询返回空；`insertByIndex` 只建指定字段。
4. **唯一约束**：`allow_null` 时空值不入索引；`withUniqueRequired` 时空值即冲突；更新两阶段（先全量校验，再应用 diff）。
5. **持久化**：`{base_dir}/Data/{type_name}.json`；只写脏表；500ms 合并；原子替换；`flush_on_drop` 默认开。
   加载时 ID 计数器修正为 `max(id)+1`，唯一冲突/无效 ID/重复 ID 跳过并记 `std.log.scoped(.zmdb)` 警告。
6. **纯内存实例**（`base_dir == ""`）：不置脏、`flush` 直接返回（防止把 `Data/` 写到进程工作目录）。

## 4. 坑与红线（已踩过）

- `zzig.fsio.writeFileAtomic` **不建父目录**（`ensureParent` 在 replace 阶段）→ 必须先 `ensureParent`（已在 `persist.zig` 封装）。
- `zzig.json.Jsmn` 要求带引号键，读不了 C# 裸键；`zzig.glob.matchPattern` 是路径语义，不能用于字段值通配。
- `zzig.db.Value.asI64` 对 NaN/超大浮点会 `@intFromFloat` panic → 本项目 `value.toI64` 先做有限性/范围检查。
- Zig 0.17：无 `BTreeMap`/`Treap`/`std.Thread.Mutex`；锁与条件变量在 `std.Io`（需传 `io`）；`{d:0>4}` 会输出 `+2024`。
- 测试里 `findBy*` 返回的 `List`、`Ref` 必须释放；`TempDb` 手工 `closeDb()` 后不要再让 `deinit` 重复关闭。
- 示例与脚本要**可重复运行**（示例开头 `clear(User)`；回归脚本每次真跑示例）。
