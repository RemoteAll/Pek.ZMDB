## 2026-11-27 · Zig 版 Pek.ZMDB 立项与完整实现

2. 「要复用 zzig 中的公共方法」

### 结论

- 以 **Rust 版 `Pek.RMDB` 的功能面**为基准（唯一约束 / 类型感知索引 / 分页 / 异步持久化 / 统计 / 全局实例），
  持久化格式与 **C# `Pek.MDB`（`SimpleJsonString`）双向兼容**。
- 全部公共能力优先复用 **zzig**，本项目只保留领域特有实现（见 `docs/与C#对照.md` 第 6 节检索证据）：
  - 复用：`zzig.db.Value`（值模型与跨类型取值）、`zzig.DateTime`（解析/格式化/Unix 换算）、
    `zzig.Buf`（序列化缓冲）、`zzig.fsio`（读文件/原子写/建目录）、`zzig.ascii`（大小写不敏感包含）、
    `zzig.web.Value`（JSON 值树）。
  - 自建：C# 裸键 JSON **宽容词法**（JSMN 要求带引号键）、**纯文本 `*`/`?` 通配**（`zzig.glob` 是路径语义）、
    **Treap 有序映射**（Zig 0.17 标准库无 `BTreeMap`）。
- 并发模型：每表一把 `std.Io.RwLock`；实体用 **原子引用计数句柄 `Ref(T)`**（对齐 Rust `Arc<T>`），
  读操作可在多线程并发，删除后延迟释放。
- 持久化：**变化驱动 + 500ms 写合并 + 条件变量零轮询 + 原子替换**；纯内存实例不置脏、不写盘。
- 所有权：`insert` / `update` / `insertBatch` 成功后实体归库所有；**失败时由库调用 `deinit` 释放**
  （与 Rust `Drop` 语义一致）；查询结果 `List` / `Page` / `Ref` 由调用方释放。

### 期间发现并修正的问题（项目侧）

- `zzig.fsio.writeFileAtomic` 在写 `*.tmp` 前不建父目录（`ensureParent` 在 replace 阶段），
  首次落盘直接 `FileNotFound`。本项目封装里先 `ensureParent`，并在注释里写明原因（未改 zzig 本体）。
- 幂等性：示例首版重复运行会因上次数据残留而触发唯一约束 → 示例开头 `clear(User)` 后即可重复执行
  （回归脚本每次都会真实跑一遍示例，能拦住这类问题）。

### 测试覆盖
- CRUD：自增 ID / 覆盖传入主键 / 更新（索引与唯一键 diff）/ 删除释放唯一值 / `findAll` 排序 / `Name`、`Id` 查询
- 分页：索引顺序取页、索引不完整退回全量排序（空值排最前）、无排序按 ID
- 索引：文本（精确区分大小写、模式不区分、范围小写字典序）、数值（跨类型）、时间（范围与年/月/日）、
  布尔智能值、JSON 文本、未建索引/未知字段
- 唯一约束：单字段、`allow_null`、`unique_required`、查找与存在性、复合唯一、更新排除自身、批量冲突保留已插入行
- 持久化：后台写盘（C# 兼容格式）、重启恢复、ID 计数器修正、读取 C# 历史文件、加载时唯一冲突跳过、
  手动 flush、写合并、`deinit` 落盘、`NotSave` 实体
- 其它：`loadedTables`、`clearAll` 持久化为空表、全局实例（含重复配置报错）、4 线程并发读

### 已知边界（如实记录）

- OOM 属致命错误：唯一索引/普通索引可能只更新一部分（不做事务回滚）；
- 文本大小写折叠只按 ASCII（中文 UTF-8 原样保留）；
- 时间索引与落盘统一**秒精度**（与 C# `yyyy-MM-dd HH:mm:ss` 口径一致）。
